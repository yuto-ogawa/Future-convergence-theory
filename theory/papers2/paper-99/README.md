## 存在判定としての創造

### Abstract


本研究は、一般的な芸術制作ではなく、キャラクター、メカ、衣装、装備、その他その構成要素など、制作開始時点では完成形が存在しない新規存在を初めて成立させるデザイン制作を対象とし、その制作を可能にする判定構造を分析する。

新規オリジナルデザインでは、模写とは異なり、完成形、変形元、唯一の正解となる参照対象が存在しない。それにもかかわらず、制作者は対象を「描きたい」と認識し、個々の形状や線が未決定の段階から制作を開始し、最終的には一つの成立した形へ収束させることができる。本研究は、この事実を「経験」「センス」「試行錯誤」「描くことで見えてくる」といった一般的説明だけでは十分に説明できない問題として扱う。

まず、参照、ラフ、線の生成、修正などの制作工程と、生成された状態を採択・確定する判定工程を区別する。また、違和感の消失は成立を保証する最終判定ではなく、制作対象が成立するための前提層に位置付けられる。さらに、「絵を描けるようになりたい」「納得できる作品を描きたい」という能力・成果志向の欲求と、「この対象そのものを描きたい」という対象志向の状態を分離する。後者は制作能力の獲得から必然的に導出されず、制作対象そのものについて先行して成立する判定である。

本研究では、この制作開始以前の判定を存在判定と定義する。存在判定とは、完成形を事前に知ることではなく、具体的形状が未決定でありながら、対象が成立可能であり、描く対象として採択されている状態を指す。参照経験や過去の制作は、個別部品の記憶だけではなく、成立可能な形態の範囲を形成する「位相」としてこの過程を支えるが、それ自体は特定対象の存在判定とは区別される。

以上から、新規オリジナル制作を、未知の形を線ごとに無制約に探索する過程ではなく、先行する存在判定を具体的な二次元表現へ保存・写像し、最終的な完成判定へ収束させる過程として再構成する。本研究は、創造を一般的な芸術性や新奇性の問題としてではなく、まだ具体的形態を持たない新規対象が、制作可能な存在として先行的に判定され、それが可視的存在へ移行する条件の問題として位置付ける。
